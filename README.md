# Автоматизация маркетингового отчета (Python + SQL)

**Marketing Report Automator** — это проект, демонстрирующий современный гибридный подход к анализу данных, где Python и SQL работают в синергии для автоматизации процесса создания ежедневного отчета об эффективности маркетинговых затрат (ROAS).

| Category      | TotalRevenue | AdSpend | ROAS  |
|:--------------|:-------------|:--------|:------|
| Спорт и отдых | 300.0        | 10.0    | 30.00 |
| Аксессуары    | 150.0        | 25.0    | 6.00  |
| Электроника   | 700.0        | 150.0   | 4.67  |

## 🚀 Ключевые Возможности

*   **Гибридный Пайплайн:** Демонстрация промышленного стандарта, где Python выступает в роли оркестратора, а вся ресурсоемкая обработка данных (JOIN, GROUP BY) выполняется на стороне базы данных SQLite.
*   **Полная Автоматизация:** Проект включает скрипт для автоматического развертывания тестовой среды, создания и наполнения базы данных.
*   **Оркестрация Процесса:** Python управляет всем процессом: от отправки SQL-запроса до выгрузки готового отчета в `.xlsx` файл.
*   **Эффективность:** Выполнение вычислений на стороне СУБД в разы быстрее и эффективнее, чем обработка больших таблиц в памяти с помощью Pandas.

## 🖇️ Разработка с ИИ-ассистентом
Проект реализован в парадигме "AI-assisted development" с использованием ИИ-ассистента (Gemini). Этот подход был выбран сознательно, чтобы отразить современный рабочий процесс, в котором аналитик данных выступает в роли архитектора и стратега, а ИИ — в роли мощного инструмента для ускорения разработки.

*   **Роль человека:** Постановка бизнес-задачи, проектирование архитектуры решения, критический аудит и отладка сгенерированного кода, интерпретация результатов.
*   **Роль ИИ-ассистента:** Генерация кода по четкому ТЗ, объяснение синтаксиса и концепций, прототипирование различных подходов, помощь в поиске и устранении ошибок.

## 🏗️ Архитектура Решения
Проект использует гибридный подход, являющийся стандартом в современной инженерии данных:
*   **SQL (Вычислительное ядро):** Вся ресурсоемкая работа — соединение таблиц, агрегация, сложные вычисления — выполняется на стороне SQLite.
*   **Python (Оркестратор):** Python управляет процессом: подготавливает среду, отправляет SQL-запрос в базу данных, забирает готовый результат и сохраняет отчет в `.xlsx` файл.

## ⚙️ Установка и Запуск

Процесс развертывания и запуска полностью автоматизирован.

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/kadence-init/marketing-report-automator
cd marketing-report-automator
pip install pandas openpyxl
```

### 2. Создание и наполнение базы данных
Эта команда создаст все необходимые таблицы в папке `data/` и файл базы данных `analytics.db`.
```bash
python generate_data.py
```

### 3. Генерация отчета
```bash
python report_automator.py
```
Готовый отчет в формате `.xlsx` появится в папке `output/`.
