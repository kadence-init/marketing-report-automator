# Автоматизация маркетингового отчета с использованием Python и SQL

## О проекте

Этот проект демонстрирует современный гибридный подход к анализу данных, где Python и SQL работают в синергии для достижения максимальной эффективности. Проект полностью самодостаточен и включает скрипт для **автоматического развертывания** тестовой среды.

Основная задача — автоматизировать процесс создания ежедневного отчета об эффективности маркетинговых затрат (ROAS). Python выступает в роли оркестратора, а вся тяжелая работа по обработке данных выполняется на стороне базы данных SQLite с помощью одного мощного SQL-запроса.

## Стек технологий
- **Python**
- **Pandas** (для оркестрации, работы с БД и выгрузки в Excel)
- **SQLite** (для хранения данных и выполнения вычислений)
- **SQL** (для основной логики обработки данных)

## Методология: Разработка с ИИ-ассистентом
Проект реализован в парадигме "AI-assisted development" с использованием ИИ-ассистента (Gemini). Этот подход был выбран сознательно, чтобы отразить современный рабочий процесс, в котором аналитик данных выступает в роли архитектора и стратега, а ИИ — в роли мощного инструмента для ускорения разработки.

*   **Роль человека:** Постановка бизнес-задачи, проектирование архитектуры решения (выбор гибридного подхода), критический аудит и отладка сгенерированного кода, интерпретация результатов.
*   **Роль ИИ-ассистента:** Генерация кода по четкому ТЗ, объяснение синтаксиса и концепций, прототипирование различных подходов, помощь в поиске и устранении ошибок.

## Архитектура решения: "Гибридный пайплайн"
Хотя данная задача могла быть решена исключительно с помощью библиотеки Pandas, был выбран гибридный подход для демонстрации промышленного стандарта эффективности и разделения труда.

*   **SQL (Вычислительное ядро):** Вся ресурсоемкая работа — соединение таблиц (`JOIN`), агрегация (`GROUP BY`), сложные вычисления — выполняется на стороне SQLite. Это в разы быстрее и эффективнее, чем загружать гигантские таблицы в память Python.
*   **Python (Оркестратор):** Python выполняет роль "дирижера". Он не занимается тяжелой работой, а управляет процессом: подготавливает среду, отправляет SQL-запрос в базу данных, забирает уже готовый, посчитанный результат и выполняет те задачи, которые SQL не умеет — сохраняет отчет в `.xlsx` файл.

Такая архитектура является стандартом в современной инженерии данных.

## Структура проекта

-   `generate_data.py` — **Скрипт для автоматического развертывания:** создает и наполняет базу данных `analytics.db`, а также сохраняет исходные данные в `.csv` файлы.
-   `report_automator.py` — Основной скрипт, который подключается к готовой базе данных и генерирует отчет.
-   `analytics.db` — Файл базы данных SQLite, **автоматически создаваемый** скриптом `generate_data.py`.
-   `data/` — Папка с `.csv` файлами как человеко-читаемая копия исходных данных.
-   `output/` — Папка, в которую сохраняются сгенерированные `.xlsx` отчеты.

## Как запустить

Процесс развертывания и запуска полностью автоматизирован.

1.  **Склонируйте репозиторий и установите зависимости:**
    ```bash
    git clone https://github.com/kadence-init/marketing-report-automator
    cd <папка_репозитория>
    pip install pandas openpyxl
    ```

2.  **Создайте и наполните базу данных:**
    Эта команда создаст файл `analytics.db` со всеми необходимыми таблицами.
    ```bash
    python generate_data.py
    ```

3.  **Сгенерируйте отчет:**
    ```bash
    python report_automator.py
    ```

4.  **Найдите результат:**
    Готовый отчет в формате `.xlsx` появится в папке `output`.
